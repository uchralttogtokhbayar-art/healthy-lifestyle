# Healthy Lifestyle — Human Development lesson

An animated presentation for a university Human Development lesson on **healthy lifestyle**: what it is, why it matters, the five pillars, behaviour change and how habits form.

**▶ View it:** https://uchralttogtokhbayar-art.github.io/healthy-lifestyle/

## Controls

| Key | Action |
| --- | --- |
| → / Space / click | Next step or slide |
| ← | Previous slide |
| F | Fullscreen |
| N | Speaker notes |
| Home / End | First / last slide |

Swipe left and right on phones. Add `#5` to the URL to open slide 5.

## Contents

1. **The concept** — WHO definitions, the burden of noncommunicable diseases, the Dahlgren & Whitehead rainbow model
2. **The five pillars** — move, eat, sleep, mind, cut
3. **Human development** — emerging adulthood, the Transtheoretical Model, habit formation
4. **Put it to work** — a daily blueprint, class activity, debate and quiz

Sources are listed on the final slide.

It is a single `index.html` file with self-hosted fonts (Oswald and DM Sans, SIL Open Font License) and no build step.
